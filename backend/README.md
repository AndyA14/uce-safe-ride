🚕 UCE Safe RideUCE Safe Ride is a distributed mobility platform designed to ensure safe and efficient transportation for the university community. The system utilizes a microservices architecture to manage rides, verify student identities, and optimize routes, integrating modern cloud tools to ensure scalability and real-time performance.📁 Project StructureBased on our current repository organization:PlaintextUCE-SAFE-RIDE/

The current roadmap includes:Auth Domain: Manages university credentials, SSO integration, and JWT issuance.Ride Domain: Handles trip creation, route matching, and status updates (Requested, In Progress, Completed).User Domain: Manages profiles (Student/Driver), reputation/ratings, and document verification.Geo Domain: Handles real-time location tracking and map integrations (Google Maps/Mapbox).🔧 Core FeaturesInstitutional Auth: Secure login strictly for university members via institutional email.Ride Matching: Intelligent algorithm to pair drivers with passengers on similar routes.Real-Time Tracking: WebSocket-based live location sharing for active rides.Safety First: "Panic Button" and "Share Ride" features for passenger security.Image Management: Profile and vehicle photo uploads managed via Amazon S3.Infrastructure as Code: Complete cloud environment provisioning using Terraform.CI/CD Pipeline: Automated testing and Docker image publishing via GitHub Actions.🐳 Running Services LocallyTo start the entire ecosystem locally using Docker:Bashdocker-compose up --build
